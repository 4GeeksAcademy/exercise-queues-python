## Bienvenido a la práctica de colas en Python

En este proyecto practicarás la estructura de datos de **colas** a través de 12 ejercicios incrementales.

## Reglas

1. Lee primero las instrucciones de cada ejercicio.
2. Usa solo Python nativo (librería estándar).
3. No uses librerías externas.
4. Implementa tu solución en app.py.
5. Ejecuta las pruebas hasta que todo pase.

## Sugerencia

Empieza por lo básico (enqueue y dequeue) y luego avanza a variantes más completas, como colas circulares, colas de prioridad y simulaciones.
