## Welcome to Practice Queues in Python

In this project you will practice **queue** data structures through 12 incremental exercises.

## Rules

1. Use only native Python (standard library).
2. Do not use external libraries.
3. Read each exercise README first.
4. Implement your solution in app.py.
5. Run tests until everything passes.

## Suggestion

Start with the basics (enqueue and dequeue) and then move on to more complete variants such as circular queues, priority queues, and simulations.
