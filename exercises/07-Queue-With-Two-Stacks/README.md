## 07 - Queue With Two Stacks

Implement a queue using two stacks (lists):

- `in_stack` for enqueue operations.
- `out_stack` for dequeue operations.

Methods:

- `enqueue(value)`
- `dequeue()`
- `peek()`

If empty, `dequeue()` and `peek()` must return `None`.

## Required variables

- `queue`: instance of `QueueWithStacks`
- `results`: results of:
  - enqueue(5), enqueue(6), dequeue(), peek(), dequeue(), dequeue()
