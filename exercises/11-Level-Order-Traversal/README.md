## 11 - Level Order Traversal

Implement level-order traversal for a binary tree (BFS using a queue).

- Class `TreeNode(value, left=None, right=None)`
- Function `level_order(root)` returns a list with BFS traversal.

If the tree is empty, return an empty list.

## Required variables

- `root`: tree with structure:
  - 1
  - children: 2 and 3
  - children of 2: 4 and 5
- `traversal_result`: result of `level_order(root)`
