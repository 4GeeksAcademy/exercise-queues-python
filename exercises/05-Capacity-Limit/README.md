## 05 - Capacity Limit

Create a queue with maximum capacity.

- Constructor: `Queue(capacity)`
- `enqueue(value)` returns `True` if inserted, `False` if full.
- `is_full()` returns whether the queue is full.

## Required variables

- `queue`: `Queue(2)`
- `enqueue_results`: list with enqueue results for 10, 20, 30.
