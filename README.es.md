# exercise-queues-python

12 prácticas incrementales para aprender colas en Python sin librerías externas.

## Estructura

- `exercises/00-Welcome`: instrucciones y bienvenida.
- `exercises/01` a `exercises/12`: prácticas progresivas.

Cada práctica incluye:

- `README.md`: instrucciones del reto.
- `app.py`: espacio para la solución.
- `test.py`: pruebas automáticas.
- `solution.hide.py`: solución de referencia.
