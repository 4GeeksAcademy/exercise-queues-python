# exercise-queues-python

12 incremental exercises to master queues in Python, from fundamentals to practical challenges.

## Structure

- `exercises/00-Welcome`: general instructions.
- `exercises/01` to `exercises/12`: progressive exercises.

Each exercise contains:

- `README.md`: challenge statement.
- `app.py`: file where the student writes the solution.
- `test.py`: automated validations.
- `solution.hide.py`: reference solution.
